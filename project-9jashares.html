Software Engineering / Web Platform 9jashares

Overview

9jashares is a production financial web platform that supports user-facing trading and investment-related workflows, including market information, account-based access, and portfolio-oriented application flows.

I contributed to backend and application development for the platform, focusing on maintainable application functionality, integrations, data-driven workflows, and production-oriented software engineering. This page describes my engineering contribution rather than marketing the product.

The Product

Based on publicly available product surfaces, 9jashares presents a financial trading web experience oriented around Nigerian capital-market and related investment workflows. Verified high-level capabilities include:

  • Presentation of financial-market information and market browsing flows
  • Account-based user workflows for traders and brokers
  • Broker-oriented integration and onboarding pathways
  • Portfolio-related application functionality
  • Transaction-oriented application flows within the trading platform

This description stays at the product-capability level and does not repeat promotional metrics, financial-performance claims, or regulatory/certification statements.

Engineering Contribution

I contributed backend and application engineering for the production platform, with emphasis on reliable user-facing workflows and maintainable software behaviour.

  • Developed backend application functionality and API-oriented features
  • Implemented and refined business/application workflows
  • Worked on data processing and persistence supporting platform features
  • Contributed to integration between application components
  • Supported debugging, maintenance, and production-oriented implementation
  • Helped improve reliability and long-term maintainability of platform software
