DaaruNaim Conference

International Conference Web Platform

Web Development / Production Platform DaaruNaim Conference

Overview

DaaruNaim Conference is a production web platform created to provide the digital presence for Daaru Na'im Academy for Shariah Sciences of Nigeria’s 18th Annual International Conference 2027.

The platform communicates conference information through a responsive public website, including event context, theme and dates, programme/schedule content, venue and contact information, papers-related sections, past events, and registration / call-for-papers pathways.

The Need

The conference needed a dedicated online presence separate from the main school website so visitors could easily find event-specific information.

  • Centralising conference information in one visitor-facing place
  • Presenting programme/schedule content clearly
  • Presenting conference theme, dates, and event context
  • Supporting visitors across desktop and mobile devices
  • Making conference content easy to update and maintain
  • Providing clear calls to action for registration and paper submission

The Platform

Based on the live public site, the platform presents a structured conference experience around:

  • About / event context for the international scholarly gathering
  • Conference theme and important-dates information
  • Call for Papers and paper-submission pathways
  • Schedule / programme information
  • Venue and contact information
  • Papers and past-events sections
  • Registration and participant login / dashboard access

The public story centres on event information, structured presentation, a responsive experience, and production deployment—not internal admin tooling.

My Contribution

I developed and contributed to the production conference web platform, focusing on delivering a maintainable public experience for visitors and participants.

  • Developed the web application and page/content structure
  • Implemented responsive frontend presentation and navigation
  • Worked on event-information presentation across major conference sections
  • Integrated frontend workflows with conference API endpoints
  • Supported registration- and paper-related visitor pathways
  • Contributed to deployment and production configuration
  • Handled debugging and production fixes

Conference branding, editorial copy, photography, and event organisation are collaborative organisational responsibilities and are not claimed as sole individual authorship here.
