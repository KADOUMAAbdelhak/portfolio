TimeTrack

Multi-Metric Forecasting Framework

Machine Learning / Time-Series Research TimeTrack

Overview

TimeTrack is a reproducible framework for studying and forecasting operational cloud telemetry across multiple resource dimensions. It supports data preparation, time-series forecasting, model training, chronological validation, benchmarking, error analysis, and experiment management for multi-metric operational signals.

The goal is to understand how operational resource behaviour can be forecast reliably, and how forecasting methods behave across different telemetry signals and forecasting horizons. The public project focuses on rigorous experimentation rather than claiming live commercial deployment.

The Problem

Cloud and distributed systems continuously produce operational telemetry, but different resource signals can behave very differently over time. Forecasting those signals can support resource planning, predictive management, capacity decisions, anomaly investigation, and application lifecycle management.

Meaningful evaluation requires more than simply training a model. Challenges include temporal dependencies, differing signal characteristics, multiple forecast horizons, avoiding data leakage, fair model comparison, reproducibility, and checking whether improvements are consistent rather than accidental.

Framework

TimeTrack structures the forecasting workflow as a reusable research and engineering pipeline:

  • Ingest and align operational telemetry
  • Clean and prepare multi-metric time-series data
  • Construct model-ready forecasting windows
  • Train forecasting models across selected signals and horizons
  • Evaluate predictions with chronological validation
  • Compare models and feature settings across forecast leads
  • Analyse errors and robustness
  • Preserve reproducible experiment outputs and artefacts

Data Scope

The framework studies multi-metric operational telemetry spanning several resource families:

CPU utilisation Memory behaviour Disk metrics Network metrics

Signals are handled as multi-metric time series for forecasting and comparison. Sensitive infrastructure identifiers and private dataset locations are not exposed here.

Engineering & Research Principles

Reproducibility

Experiments are structured so configurations, predictions, metrics, and results can be reproduced and compared.

Chronological Validation

Forecasting evaluation respects temporal order rather than using random train/test splitting.

Multi-Metric Evaluation

Models are evaluated across different resource signals instead of assuming one approach behaves identically everywhere.

Robust Comparison

Performance is assessed through structured benchmarking and error analysis rather than a single headline metric.

Models & Methods

The public repository includes classical and neural forecasting approaches used for baseline comparison and scientific benchmarking:

  • Persistence baseline
  • Ridge regression
  • LightGBM
  • DLinear
  • LSTM
  • PatchTST-style encoder

Evaluation

Evaluation emphasises chronological validation, horizon-aware comparison, and structured error analysis across models and telemetry signals. Core forecasting metrics used in the repository include:

MAE RMSE R²

This page intentionally avoids headline performance claims; the repository remains the source for detailed experiment outputs and comparisons.
