OSR

Semantic Deployment Integration

Software Engineering / Cloud-Edge Research OSR

Overview

OSR is a software integration component developed in the context of the EU-funded AC3 project. It connects structured and semantic application information with cloud-edge application lifecycle and deployment workflows.

Its purpose is to improve interoperability between application descriptions, catalogues, and the systems responsible for deploying and managing applications across heterogeneous cloud-edge environments. The work contributed to the successful completion of the AC3 project as part of a collaborative research effort.

The Challenge

Cloud-edge ecosystems involve multiple systems, application descriptions, catalogues, deployment mechanisms, and data models. Those components need a consistent way to exchange and interpret application information.

Without interoperability, application metadata can become difficult to reuse across catalogue, orchestration, and lifecycle-management systems. OSR addresses this gap by helping connect semantic application information with operational deployment workflows.

Approach

At a high level, the work involved integrating structured application metadata with cloud-edge lifecycle processes:

  • Working with structured application metadata and semantic models
  • Validating metadata structures for consistent interpretation
  • Supporting catalogue integration workflows
  • Translating and mapping semantic information into deployment-oriented application representations
  • Integrating with cloud-edge application lifecycle workflows

Supporting standards and technologies in this context include DCAT-AP, Gaia-X concepts, and SHACL-based validation, used where relevant to interoperability rather than as the product headline.
