DynAPM

Predictive Application Profile Maintenance

Machine Learning / Research Engineering DynAPM

Overview

DynAPM is a predictive application-profile maintenance approach designed to keep resource profiles aligned with changing workload behaviour. It combines workload forecasting, time-series analysis, residual-based monitoring, and online drift detection to identify when application resource profiles should be updated.

The approach was evaluated using workload traces from 1,576 production virtual machines, with the goal of improving how well application profiles reflect actual resource demand and reducing SLA-related risk. The evaluation used production VM traces; this page does not claim live commercial deployment of DynAPM itself.

The Problem

Static application resource profiles can become inaccurate as workload behaviour changes over time. Poorly maintained profiles can lead to over-provisioning, under-provisioning, inefficient resource allocation, and a higher risk of SLA violations.

DynAPM investigates whether forecasting and drift detection can help identify when application profiles should be updated so that profile classes remain better aligned with observed demand.

Approach

At a high level, the work involved preparing workload telemetry, building forecasting pipelines, generating predictions, analysing prediction residuals, detecting workload changes, updating and evaluating application-profile classes, and comparing the approach against a matched baseline.

  • Time-series forecasting for workload behaviour
  • Residual-based monitoring and online drift detection
  • Application resource profiling and profile-class evaluation
  • Reproducible ML experimentation and baseline comparison

Outcomes

Verified evaluation results from the DynAPM study:

+13.0 percentage points CPU profile-class accuracy
+14.5 percentage points Memory profile-class accuracy
28% reduction SLA-risk events
1,576 production VMs Traces used for evaluation
